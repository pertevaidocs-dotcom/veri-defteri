# Veri Defteri

Cihazda çalışan yapay zekâ ile tablo denemesi. İlk kullanımda Qwen3 1.7B modeli indirilir. Kayıtlar tarayıcının IndexedDB veritabanında saklanır; bulut senkronizasyonu yoktur. Çevrimdışı model kullanımını cihazda ayrıca doğrulayın.

GitHub Pages: Settings → Pages → Deploy from a branch → main / root. HTTPS kullanın.

WebLLM runtime: Apache-2.0. İlgili lisans bildirimi webllm-local.js içindedir.
